# Contributing

Thanks for helping improve this beginner project.

## Before you start

- Keep the project dependency-free and usable by opening `index.html` directly.
- Preserve the exercise's TODOs and acceptance criteria; the starter must remain intentionally incomplete.
- Keep changes focused; open a separate issue or pull request for unrelated work.
- Do not commit credentials, personal data, generated build output, or editor-specific files.

## Test your change

1. Open `index.html` directly in a current browser.
2. Check local links and assets, keyboard navigation, 320px width, and 200% zoom.
3. Validate changed HTML with the [Nu HTML Checker](https://validator.w3.org/nu/).
4. Re-read the project checklist and confirm the starter remains intentionally unsolved.

In a pull request, explain the problem, the smallest change you made, and how you tested it. By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
